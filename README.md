# 理想汽车批量埋点助手

**在用户增长运营中心快速批量创建埋点，并自动将事件名称、事件标识回写到埋点表，减少逐条手动配置。**

首次使用只需记住：

1. 在 AI 客户端选择**本机/本地执行**，连好公司网络。Codex 选择“本机 / This computer”。
2. 发 PRD 或埋点表链接；首次按提示登录自己的飞书和运营平台。
3. 审核 AI 整理的标准表。确认后 AI 执行创建和回写，日常不用自己敲终端。

有埋点表会帮你规范；没有表会从 C 端需求梳理；缺截图时从平台补图，优先保留 PRD/用户提供的页面图。每次调用检查云端更新，有更新先提示，由使用者确认后安装。

适用于 Codex、Claude Code，以及接入 MiMo、DeepSeek 等模型、具备本机文件和终端能力的 AI 客户端。模型名不决定执行能力。纯网页或云端对话不能自动复用电脑里的内网和浏览器登录，首次使用会明确引导。

## 一条命令安装（macOS / Linux）

在本机终端粘贴下面一条命令，也可以让本机 AI 助手执行。无需 GitHub 登录：

```bash
curl -fsSL https://raw.githubusercontent.com/javenvian-del/li-auto-event-tracking/main/install.sh | bash
```

默认同时安装 Codex 和 Claude Code。自动复用 Node.js 20+；缺少时从 Node.js 官方下载技能专用运行环境并校验，不需要管理员权限。依赖自动准备。其他客户端可安装到其实际支持的技能目录；不支持自动发现时，让助手先读取 SKILL.md。[安装与跨客户端说明](references/setup.md)。

已装旧版的同事需要先更新一次，才能获得后续“每次调用检查更新”的能力。更新保留本机配置、个人登录状态和业务日志。

安装和更新检查均可匿名完成。实际处理业务材料时，需要使用者自己的公司网络、飞书和运营平台授权。公开代码不提供任何公司的业务访问权限。

## 使用边界

PRD 和原型只读；独立生成审核表，审核后才创建。已有结果跳过，提交结果不明确就停止查证。截图、凭据和业务数据只保留在本人环境，发布包只有代码与说明。脚本不调用模型 API；AI 理解需求和处理异常仍有模型用量。

macOS 已验证本机脚本流程；Linux/Windows 与其他客户端需按实际环境检查。Windows 提供 Node/run.cmd 入口，尚未进行完整实机验证。
