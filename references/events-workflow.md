# 现成标准表格：预检、创建与回写

1. 使用本次明确给出的表格链接，读取真实工作表名称和 A–J 表头。飞书已有本人授权的 CLI/API 时优先使用，加载所在客户端可用的飞书技能；没有相关工具时使用本人已登录浏览器。非标准列转到 PRD 整理流程，不直接改源表。
2. 先按 [浏览器执行权限](setup.md#浏览器执行权限) 确认宿主已允许本次 Chrome 命令；再首次配置或切换表格：

   ```bash
   bash run.sh init --sheet-url '本次表格链接' --sheet-name '实际工作表名' --platform-url '用户确认的事件管理页链接'
   bash run.sh check-login
   ```

   配置的公司平台地址可复用；本次表格不能用历史链接替代。缺少平台地址再问一次。要求 `feishu: ready` 和 `platform: ready`；失败才执行 `bash run.sh login`。让使用者在弹出的专用 Chrome 登录，告知助手已完成后，由助手向正在等待的进程发送回车并复查，不要求使用者敲终端命令。API 授权与脚本专用 Chrome 登录是不同会话。
3. 本次未给范围时，询问处理哪些行、跳过哪些行；已有范围不重复问。执行 `bash run.sh events-check --rows 6-18`，离散行用 `6-18,20`，排除用 `--exclude 10-12`。
4. 展示审核表链接、行范围和预检结果；用户已明确审核同意或明确要求创建时，按同一范围执行 `bash run.sh run --rows 6-18 --confirmed`。预检后编辑过表格或图片须重新预检。
5. 等待退出，失败只读本次日志末尾；成功返回新建、跳过、恢复回写数量。`bash run.sh status` 只读最近批次记录，不代表实时登录状态。
